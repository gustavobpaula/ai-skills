# Scenario: specification plus implementation request

## Prompt

Use `$spec` to define and implement a dismissible notification banner. The message is provided by the parent component, dismissing hides it for the current page session, and no persistence is needed.

## Context

- The temporary project is a small existing frontend.

## Expected behavior

- Complete the specification workflow first.
- Present a concise draft and wait for approval before writing it.
- Keep any later implementation work separate from the specification stage.

## Must not

- Write application code while preparing or awaiting approval of the specification.
- Introduce persistence, global state, analytics, or design-system requirements.
